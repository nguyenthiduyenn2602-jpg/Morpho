这次更新，给现实中的你留一个来信入口，也让你与角色的故事多一点画面。

✉ Morpho 热线 · 写给大壮

桌面的「Morpho热线」正式上线，点进去就是「大壮法律热线」。法律疑问、让你不舒服的规则，或成长中的迷茫，都可以从一段文字开始。

  • 首版仅支持免费文字投稿，不接收图片、视频和文件。
  • 填写年龄、性别与职业，帮助理解事情背景；不要求真实姓名，不用于用户画像或统计。
  • 期待回信可以自愿留下邮箱，不保证逐一回复或选用。
  • 仅将主动提交的内容保存到热线后台，不读取角色、聊天记录和其他相册内容。

投稿可能由 AI 辅助阅读和整理，并可能在隐去真实姓名、联系方式等可识别信息后，用于视频、直播或切片讨论。特殊经历仍可能被熟人认出，请勿提交不适合公开讨论的材料。提交前会再次提示并确认。

入口：小手机桌面 → Morpho热线 → 写给大壮

🎨 见面剧情 · 配图更顺手

写故事与生图导演，各用合适的模型

新增「生图导演独立 API」：可从已有 API 预设填入配置，获取并搜索模型、测试连接、保存。开启后仅用于整理画面与生图提示词；正文仍用剧情模型，实际出图继续使用生图 2.0。关闭后恢复跟随剧情模型。

调好一次，存成自己的配图预设

画师串、你与各角色的提示词、负面词、画幅都能自定义名称保存，支持载入、更新、改名和删除，不同剧情共用。

人物按角色身份匹配，未匹配角色保留当前提示词。预设不包含 API 配置；载入后可继续调整，点击「保存配图设置」才应用到当前剧情。接口测试和生成消耗所配置服务的额度。

入口：见面 → 具体剧情 → 顶部配图设置
